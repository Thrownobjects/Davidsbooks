# Davidsbooks
a site that has links to davids books

## Customize the bookshelf

Open `index.html` and update each of the four book cards with the book's title,
description, and Amazon product link. Replace the `REPLACE_WITH_BOOK_n_ASIN`
part of each link with the book's Amazon ASIN. The site is a static page and
does not require a build step or dependencies; publish `index.html` on any
static web host.
